# score-library

score-library is a program for storing and searching through physical sheet music in a library.

## Features

- Store composers with basic metadata (name, years, nationality)
- Store pieces with ID, title, composer and instrumentation
- Search for pieces by composer

## Technology

- Kotlin JVM
- Gradle (Kotlin DSL)
- JUnit 5 for tests

## Build and test

Requires JDK 21.

Build the project:

```bash
./gradlew build
